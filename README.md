# TradeFlow AI Frontend

Vue 3 前端工作台，用于外贸 AI 跟单助手的客户、询盘、AI 分析、报价草稿和任务提醒界面。

## Stack

- Vue 3
- TypeScript
- Vite
- Element Plus
- Pinia
- Vue Router
- Axios

## Development

```bash
pnpm install
pnpm dev
```

默认代理后端网关：

```text
http://localhost:8080/api
```

演示账号：

```text
admin / admin123
```

## Build

```bash
pnpm build
```
